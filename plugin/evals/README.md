# Pocket CEO eval suite

Generated by `dev/make_evals.py` (edit the cases there, not here). Each case pins a realistic owner:
`scaffold.sh` recreates their `~/Documents/Pocket CEO/` (profile, and for bookkeeping cases six months of
imported bank history, receipts and invoices, shifted to the day you run it). Expected numbers in the
graders come from the tested calculator, which matches all 336 published 2026 marginal tax rates.

Run (from `plugin/`; needs `bubblewrap` and `socat` on Linux for the Bash sandbox):

    claude plugin eval . --scaffold --allow-tools Bash WebSearch --trust-plugin

Each case runs twice: with Pocket CEO and plain Claude ("without"). Read the delta, not just the
score. The `uses_skill` graders show whether the right skill fired; they don't count toward the score.

Caveats: the eval sandbox's home folder is read-only to the agent, so cases ask questions about records
that already exist (bank history, receipts, invoices) rather than importing new files, and plain Claude
sees the same scaffolded files. In real use those files only exist because Pocket CEO built them, so the
bookkeeping cases understate the real-world difference.
