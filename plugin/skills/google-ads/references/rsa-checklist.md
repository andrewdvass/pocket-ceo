# Responsive search ad: output format and checklist

```
Campaign: [Service] - [City]
  Ad group: [intent, e.g. emergency furnace repair]
    Keywords: [exact] and "phrase" variants (5 to 15)
    Negatives: (ad group level, on top of the shared lists)
    Headlines (max 30):
      H1 (pin 1, optional): "Calgary Furnace Repair" [22]
      H2: "Same-Day Service" [16]
      ... 15 in total
    Descriptions (max 90):
      D1: "Licensed techs, upfront pricing. Book online or call now for same-day repair." [80]
      ... 4 in total
    Final URL: the matching service page (not the home page)
    Paths: /furnace-repair /same-day (max 15 each)
  Assets: sitelinks x4, callouts x4-6, structured snippet (Services), call, location, price (optional)
Bidding: [strategy and why]   Daily budget: [$]   Target cost per lead: [$, from their numbers]
```

- [ ] Every line shows its character count; nothing over the limit
- [ ] 3+ headlines contain the main keyword or a close variant
- [ ] No two headlines say the same thing; all work in any combination
- [ ] Each description stands alone and at least two include a call to action
- [ ] Proof is real (reviews, licences, years) and from the owner's memory
- [ ] Urgency or offers only if true; no exclamation marks in headlines
- [ ] Landing page headline matches the ad's promise
- [ ] French versions for Quebec audiences
