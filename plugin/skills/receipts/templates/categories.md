# Expense categories (CRA form T2125 lines, sole proprietors)

Use these names in the Category column so the accountant can copy totals straight onto the return.
Corporations use the same groupings on their books.

| Category | Examples | Notes |
|---|---|---|
| Advertising | Facebook/Google ads, flyers, sponsorships | |
| Meals and entertainment | Client lunch, coffee meeting | Usually 50% deductible |
| Bad debts | Invoices you'll never collect | |
| Insurance | Business liability, professional insurance | Not life insurance |
| Interest and bank charges | Card fees, business loan interest, Stripe/Square fees | |
| Business taxes, licences, memberships | Business licence, college/association dues | |
| Office expenses | Pens, paper, printer ink, small supplies | |
| Supplies | Things used up delivering your service or product | |
| Legal, accounting, professional fees | Accountant, lawyer, bookkeeper | |
| Management and administration fees | | |
| Rent | Office or studio rent | Home office is separate |
| Repairs and maintenance | | |
| Salaries, wages, benefits | Staff pay, employer CPP/EI | |
| Property taxes | Business property | |
| Travel | Flights, hotels, taxis for business | Not commuting |
| Telephone and utilities | Phone, internet | Business-use % only |
| Fuel costs (except motor vehicles) | | |
| Delivery, freight, express | Shipping, couriers | |
| Motor vehicle expenses | Gas, insurance, repairs, parking | Business-use % from a km log |
| Software and subscriptions | SaaS, apps, Claude, Canva | Often under Office expenses on the form |
| Business-use-of-home | Share of rent/mortgage interest, heat, power | Calculated at year end |
| CAPITAL | Computer, camera, furniture, equipment (usually $500+) | Depreciated (CCA), not expensed at once |
| Personal (not deductible) | | Logged so nothing is missing, excluded from totals |
